# Max_Effect
EECS 473 project repo

Guitar effect pedals are popular sound-manipulating devices that adjust a player's sound, but there are many types to choose from, and they often require chaining multiple pedals together, which gets expensive very quickly. The solution is to combine different effect types to save space and avoid choosing just one. Our project, Max Effect, is a battery-powered digital effects pedal that serves as an all-in-one system for guitarists. It will incorporate a detachable whammy bar, distortion, reverb, a looper, note detection for tuning and MIDI output, and an LCD screen for user interaction. This guitar pedal will be easy to use and will have preset buttons to save modification settings.
